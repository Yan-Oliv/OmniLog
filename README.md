# Omnia — Gestão Logística (build web)

![Flutter Web](https://img.shields.io/badge/Flutter%20Web-02569B?style=flat-square&logo=flutter&logoColor=white) ![PWA](https://img.shields.io/badge/PWA-5A0FC8?style=flat-square&logo=pwa&logoColor=white) ![Logística](https://img.shields.io/badge/Logística-f18a4b?style=flat-square)

Versão **web publicada** (build Flutter Web, instalável como PWA) do sistema de gestão logística que deu origem ao **OmnyaLog**. Este repositório guarda apenas os artefatos de build; o código-fonte é mantido em repositório privado.

## Destaques

- PWA com *service worker*, página offline e *splash* próprios
- Interface responsiva para desktop e celular

O **OmnyaLog** está em operação em [log.omnyatech.com.br](https://log.omnyatech.com.br/).
